# ⚡ Web Performance & Core Web Vitals Auditor

An automated Python tool designed to evaluate web application latency, asset sizes, and metric scores with actionable optimization recommendations.

## 🚀 Features
- **Latency Tracking:** Measures response time and estimated Time to First Byte (TTFB).
- **Payload Analysis:** Calculates total page content size in KB.
- **Automated Recommendations:** Offers real-time optimization suggestions for caching and asset compression.
- **Zero External Dependencies:** Built entirely with standard Python libraries.

## 🛠️ Installation & Usage
Ensure you have Python 3.x installed.

```bash
# Run the auditor on any target website
python web_auditor.py
